1. Co umí

Veřejný MCP connector pro hledání českých nabídek pronájmu a prodeje, nové nabídky podle first_seen, kontrolu férovosti ceny a srovnání lokalit. Každý výsledek má odkaz na zdrojový portál i Realitify. Bez přihlášení, pouze čtení.

Lokality a dispozice se normalizují (Praha 5 / Smíchov / Prague 5; 2kk / 2+kk / dvoupokojový). Neznámá lokalita vrací chybu s návrhy — ne prázdný seznam bez vysvětlení.

2. URL serveru

https://mcp.realitify.cz/mcp

Transport: Streamable HTTP. Health: https://mcp.realitify.cz/health. Jednotky: CZK, m². Odpovědi obsahují data_as_of.

Související: index nájmů, trh Praha, llms.txt, llms-full.txt.

3. Nástroje

search_listings — lokalita, offer_type (pronajem|prodej), cena, dispozice, plocha; řazení newest|cheapest|best_value; max 20.

new_listings — nabídky poprvé viděné za posledních X hodin.

get_listing — detail podle id nebo listing_key.

locality_stats — počet aktivních, průměr/medián ceny a Kč/m².

price_check — je cena férová vs srovnatelné nabídky (percentil, vs_avg_pct).

compare_localities — statistiky více lokalit vedle sebe.

Anotace u všech: readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=false.

4. Přidání do Claude

V Claude otevřete Connectors a přidejte vzdálené MCP URL https://mcp.realitify.cz/mcp. Veřejný connector nevyžaduje API klíč.

5. Přidání do ChatGPT

V ChatGPT Apps zvolte variantu With MCP a zadejte https://mcp.realitify.cz/mcp. Podle potřeby ověřte doménu realitify.cz.

6. Příklady promptů

„Hledám 2+kk v Praze do 20 000 Kč měsíčně.“

„Co nového přibylo v Praze 5 za posledních 24 hodin?“

„Je 25 000 Kč za 2+kk 55 m² v Brně férová cena?“

„Porovnej průměrný nájem v Praze, Brně a Ostravě.“

„Otevři detail nabídky z předchozího hledání.“
