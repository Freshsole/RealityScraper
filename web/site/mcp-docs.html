TOOLS

Six tools for working with the market

All tools set readOnlyHint=true, destructiveHint=false, idempotentHint=true and openWorldHint=false. Localities and layouts are normalised (Praha 5 / Smíchov / Prague 5; 2kk / 2+kk).

search_listings

Browse and filter current listings: locality, offer_type, price, layout, area, sort newest | cheapest | best_value, max 20.

new_listings

Listings first seen in the last N hours.

get_listing

One listing by id or listing_key from a prior search.

locality_stats

Active count, average and median price and CZK/m² for a locality.

price_check

Is an asking price fair versus comparable listings (percentile, vs_avg_pct).

compare_localities

Statistics for two or more localities side by side.

EXAMPLES

What you can ask

Use it when you look for a flat or house in Czechia or ask about prices and availability. An unknown locality returns an error with suggestions, not an empty list.

„Find a 2+kk in Prague under 20,000 CZK per month.“

„What is new in Prague 5 in the last 24 hours?“

„Is 25,000 CZK for a 55 m² 2+kk in Brno a fair price?“

„Compare the average rent in Prague, Brno and Ostrava.“

„Open the details of a listing from the previous search.“
