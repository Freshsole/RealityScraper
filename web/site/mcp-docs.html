REALITIFY MCP

Read-only Czech listings for Claude, ChatGPT and compatible MCP clients

Server URL

https://mcp.realitify.cz/mcp (Streamable HTTP, no login)

Health: https://mcp.realitify.cz/health

Units: CZK, m². Data region: Czech Republic. Every tool response includes data_as_of, units, source, and source_url.

When to use

Use when the user looks for a flat/apartment/house to rent or buy in Czechia, asks about current listings, prices, or availability. Examples: “hledám byt”, “pronájem Praha 2+kk”, “flat in Prague under 20000”, “je 25000 za 2+kk hodně?”.

Tools

  • search_listings — Use when browsing/filtering current listings. Do not use for “what is new in last N hours” (use new_listings).
  • new_listings — Use for first_seen in the last N hours. Do not use for general search without a time window.
  • get_listing — Use for one id/listing_key from a prior search. Do not invent ids.
  • locality_stats — Use for active count / median / avg price and Kč/m². Do not use when the user wants listing cards.
  • price_check — Use to judge if an asking price is fair (median primary). Do not use without an asking price.
  • compare_localities — Use for 2+ localities side by side.

All tools: readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=false.

Response fields

Listings include price_czk, price_per_m2 (CZK/m²), price_vs_locality_pct, area_m2, disposition, locality, floor (if known), first_seen, portal, source_url, realitify_url, data_as_of, and realitify_tip (Start 149 CZK/month, PRO 349 CZK/month).
