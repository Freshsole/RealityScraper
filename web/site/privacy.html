Data we process

For the Realitify web app we process account data (name, email, phone if provided), monitor settings, and technical logs needed to run the service. Details in Czech: /ochrana-soukromi.

3

Public MCP connector

The public MCP server at https://mcp.realitify.cz/mcp is read-only. It accepts search parameters from AI clients (locality, rent/sale, price, disposition, area, limit, listing id). It does not store AI chat transcripts or end-user names from Claude/ChatGPT.

Logging: client IP (in-memory rate limiting), request time, and response status. Listing responses strip broker names and phone numbers even if source portals contain them.

Retention: in-memory rate-limit counters expire within about 60 seconds or on process restart. Infrastructure access logs, if enabled, are kept for at most 30 days.
