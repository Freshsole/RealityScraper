1. What it does

The Realitify MCP connector lets AI assistants search aggregated Czech rental and sale listings, open a listing detail, and fetch locality price statistics. Every result includes the original portal link and a Realitify deep link. No login. Read-only.

2. Server URL

https://mcp.realitify.cz/mcp

Transport: Streamable HTTP. Health check: https://mcp.realitify.cz/health.

3. Tools

search_listings — filter by locality, offer type (pronajem/prodej), price, disposition, area; max 20 results.

get_listing — detail by numeric id or listing_key.

locality_stats — active listing count and average CZK/m² for a locality.

All tools are annotated readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=false.

4. Add in Claude

In Claude, open Connectors / custom connectors and add the remote MCP URL https://mcp.realitify.cz/mcp. No API key is required for the public connector. After approval in the Claude Connectors Directory, you can also enable it from the directory listing.

5. Add in ChatGPT

In ChatGPT Apps / connectors, choose an app With MCP and point it at https://mcp.realitify.cz/mcp. Follow OpenAI’s domain verification steps for realitify.cz if prompted.

6. Example prompts

“I'm looking for a 2+kk flat in Prague under 20,000 CZK rent.”

“Show average rent per m² in Brno.”

“Open listing details for id … from the previous search.”

“Find 3+1 apartments for sale in Ostrava under 4,000,000 CZK.”

“Compare active rental counts for Praha vs Brno.”
