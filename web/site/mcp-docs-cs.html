1. Co umí

Veřejný MCP connector umožní AI asistentům hledat agregované české nabídky pronájmu a prodeje, otevřít detail nabídky a zobrazit statistiky lokality. Každý výsledek obsahuje odkaz na zdrojový portál i na Realitify. Bez přihlášení, pouze čtení.

2. URL serveru

https://mcp.realitify.cz/mcp

Transport: Streamable HTTP. Health: https://mcp.realitify.cz/health.

3. Nástroje

search_listings — lokalita, typ (pronajem/prodej), cena, dispozice, plocha; max 20 výsledků.

get_listing — detail podle id nebo listing_key.

locality_stats — počet aktivních nabídek a průměr Kč/m².

4. Přidání do Claude

V Claude otevřete Connectors a přidejte vzdálené MCP URL https://mcp.realitify.cz/mcp. Veřejný connector nevyžaduje API klíč.

5. Přidání do ChatGPT

V ChatGPT Apps zvolte variantu With MCP a zadejte https://mcp.realitify.cz/mcp. Podle potřeby ověřte doménu realitify.cz.

6. Příklady promptů

„Hledám 2+kk v Praze do 20 000 Kč měsíčně.“

„Jaká je průměrná cena za m² pronájmu v Brně?“

„Otevři detail nabídky z předchozího hledání.“
