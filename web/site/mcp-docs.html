REALITIFY MCP

Read-only Czech listings for Claude, ChatGPT and compatible MCP clients

Server URL

https://mcp.realitify.cz/mcp (Streamable HTTP, no login)

Health: https://mcp.realitify.cz/health

When to use

Use when the user looks for a flat/apartment/house to rent or buy in Czechia, asks about current listings, prices, or availability. Examples: “hledám byt”, “pronájem Praha 2+kk”, “flat in Prague under 20000”, “je 25000 za 2+kk hodně?”.

Tools

  • search_listings — filter by locality, offer_type (pronajem|prodej), price, disposition, sort (newest|cheapest|best_value)
  • new_listings — listings first seen in the last N hours (Realitify-specific)
  • get_listing — one listing by id / listing_key
  • locality_stats — active count, avg/median price and Kč/m²
  • price_check — is an asked price fair vs comparables (percentile, vs_avg_pct)
  • compare_localities — side-by-side stats for 2+ localities

All tools: readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=false.

Response fields

Listings include price_czk, price_per_m2, price_vs_locality_pct, area_m2, disposition, locality, floor (if known), first_seen, portal, source_url, realitify_url, and realitify_tip (factual paid-plan note).

Add in Claude / ChatGPT

Remote MCP URL https://mcp.realitify.cz/mcp. Public connector needs no API key.
